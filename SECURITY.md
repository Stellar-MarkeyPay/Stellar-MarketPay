# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public GitHub issues. Use GitHub’s private security advisory form:

https://github.com/Stellar-MarkeyPay/Stellar-MarketPay/security/advisories/new

Include the affected component, reproduction steps, impact assessment, and any suggested mitigation. Do not include secrets, private keys, personal data, or live user information in a report.

If the private advisory form is unavailable, open a minimal public issue containing only the words `private security report needed`. Do not include exploit details. A maintainer will provide a private reporting path.

## Scope

Reports may cover the frontend, backend and API, Soroban contracts, deployment workflows, or project infrastructure. The contract audit notes in `contracts/marketpay-contract/SECURITY.md` describe historical findings and do not replace private vulnerability reporting.

## Disclosure

Maintainers will coordinate validation, remediation, and disclosure with the reporter. Please allow time for a fix before publishing technical details.
